# GrooveMap

Live Band 錄音 → Cubase Tempo Map / Click / Marker MIDI

## 使用方法

1. 解壓整個資料夾
2. 雙擊 GrooveMap.exe
3. 選擇 WAV / AIFF 錄音檔
4. 按「開始分析」
5. 按「Export Cubase」
6. 到 Cubase 匯入 *_Cubase.mid

## 系統需求

- Windows 10 / 11 64 位元
- 不需要安裝 Python

## 常見問題

- Windows Defender 警告：選「仍要執行」，這是 PyInstaller 的正常誤判
- 閃退：把 exe 拖到 CMD 裡執行看錯誤訊息
- 一定要解壓整個資料夾，不要只拉 exe 出來
